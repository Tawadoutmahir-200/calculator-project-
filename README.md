# Calculator Project

# About the Project
This is a simple calculator program made using Python.  
Each student in our team added one math operation to the project.

# Team Work
- Student 1: Addition (+)  
- Student 2: Subtraction (-)  
- Student 3: Multiplication (*)  
- Student 4: Division (/)  
- Student 5: Project manager (GitHub setup and merging)

# Features
- Add two numbers  
- Subtract two numbers  
- Multiply two numbers  
- Divide two numbers (with error if dividing by zero)  

# How to Use
1. Open calculator.py in Python.  
2. Run the program.  
3. Enter the first number, the operator (+, -, *, /), and the second number.  
4. See the result printed on the screen.
# Example
Enter first number: 10
Enter operator (+, -, *, /): -
Enter second number
Result: 6
